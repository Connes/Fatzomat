# together – Clean Home Assets

This folder contains the production-ready visual assets for the together home screen.

- `icons/`: four isolated 1024x1024 main-choice illustrations with transparent margins.
- `branding/`: transparent together wordmark used in the home header.
- `background/`: warm cream organic-wave background with subtle food-inspired corner decoration, designed as a responsive backdrop.

The four main icons are rendered with `BoxFit.contain`. The home background is used as a full-screen `BoxFit.cover` layer. Cards, CTA and navigation remain native Flutter widgets.
