# Schmackofatz V1.7.0

## Zwei-Personen-Entscheidungsworkflow

- Realtime-Aktualisierung von `decision_requests` auf dem Entscheidungsbildschirm.
- Realtime-Kanal wird beim Verlassen des Entscheidungsbildschirms sauber entfernt.
- Eingehende Statusänderungen werden ohne manuellen Reload übernommen.
- Bestehende Decision-Request-Zustände und Supabase-RPCs bleiben unverändert.
- Keine OpenAI-API-Anbindung.
- Keine neue Supabase-Migration erforderlich.
