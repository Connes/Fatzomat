# Schmackofatz UI/UX Redesign

## Implemented

- Centralized visual design tokens in `lib/core/app_design.dart`.
- Refreshed warm food-focused palette with primary, accent, semantic and muted colors.
- Expanded Inter typography hierarchy from display to labels and captions.
- Unified radius, spacing, motion and component sizing tokens.
- Updated Material 3 themes for cards, buttons, inputs, chips, dialogs, bottom sheets, navigation, snackbars, FABs, checkboxes and progress indicators.
- Added reusable `AppBadge` and refined `AppSurface`, `MetaPill`, `SectionHeader` and `BrandMark` styling.
- Updated app navigation styling and preserved `IndexedStack` state between tabs.
- Modernized the dedicated shopping-list entry state.
- Modernized the detailed shopping-list view with status badge, progress summary, responsive surfaces and animated checked-item styling.
- Kept existing Single/Connect shopping-list data flow and Supabase Realtime behavior intact.
- Added compatibility aliases in the design system so existing feature screens can migrate without breaking behavior.
