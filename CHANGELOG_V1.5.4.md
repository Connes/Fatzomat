# Schmackofatz V1.5.4

## Umbenennung der App

- Der sichtbare Produktname wurde auf **Schmackofatz** umgestellt.
- Der Name wird im Flutter-App-Titel, in der sichtbaren Markenanzeige und auf dem Startbildschirm verwendet.
- Android zeigt **Schmackofatz** als Launcher-Namen an.
- iOS verwendet **Schmackofatz** als Display Name und Bundle Name.
- Die technische Paket-/Application-ID `food_app_mvp` bleibt unverändert, damit keine unnötige technische Migration oder Änderung bestehender Installationen erforderlich wird.
- Das technische Rezeptaustauschformat `together_recipe` bleibt unverändert und damit kompatibel.
