# together V1.5.2

## ChatGPT-Rezeptworkflow ohne API-Kosten

- „Mit ChatGPT erstellen“ startet jetzt mit einer Zutaten-Auswahl analog zum bestehenden „Wir kochen“-Flow.
- Die Hauptauswahl (Rind, Schwein, Huhn, Fisch oder Vegetarisch) und die gewählten Zutaten werden in einen strukturierten Prompt übernommen.
- Der vollständige Prompt wird automatisch in die Zwischenablage kopiert.
- Auf Android wird die installierte ChatGPT-App geöffnet; falls sie nicht verfügbar ist, wird ChatGPT im Browser geöffnet.
- ChatGPT wird angewiesen, ausschließlich ein `together_recipe`-JSON in Version 1 zurückzugeben.
- Das erzeugte JSON kann anschließend über „Rezeptdatei importieren“ in together gespeichert werden.
- Es wird keine OpenAI-API und kein zusätzliches API-Budget benötigt.
