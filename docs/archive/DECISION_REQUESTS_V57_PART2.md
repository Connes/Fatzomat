# V57 / Part 2 – Entscheidung starten

Die UI für Entscheidungsanfragen ist jetzt vorhanden. Eine verbundene Person kann auf der Startseite eine Anfrage senden. Die empfangende Person sieht einen „Du bist dran“-Bereich und kann die Entscheidung starten.

## Ablauf

1. Sender erstellt eine Anfrage.
2. Empfänger sieht die Anfrage per Realtime und öffnet sie.
3. Empfänger bestätigt die Anfrage.
4. Auswahl: Kochen, Bestellen, Essen gehen oder Überrasch mich.
5. Bei Kochen wird die bestehende Rezeptsuche mit der Request-ID gestartet. Beim Festlegen des Rezepts für Heute wird die Anfrage in Teil 3 aufgelöst.
6. Bei Bestellen/Essen gehen wird die gewählte Richtung sofort als Ergebnis der Anfrage gespeichert.

Es gibt weiterhin kein Chat-System und keine Bestellung/Reservierung innerhalb von Mahlzeit.
