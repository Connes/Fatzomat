# Release v36

- Neue Startseite: „Auf was hast du Bock?“
- Hauptauswahl: Rind, Schwein, Huhn, Fisch, Vegetarisch, Überrasch mich.
- „Überrasch mich“ wählt clientseitig zufällig eine der fünf Hauptauswahlen.
- Zweite Seite: weitere Lebensmittel aus der Lebensmittelliste.
- Gewürze, Saucen und Grundzutaten werden dort nicht angezeigt.
- Rezeptsuche erst auf der zweiten Seite.
- Personen, Kochzeit und Küche sind auf diesem Flow nicht sichtbar und bleiben auf sinnvollen Standardwerten.
- Backend akzeptiert die Hauptauswahl separat und schließt Dislikes aus.
- Vegetarische Rezepte werden zusätzlich serverseitig auf Fleisch/Fisch geprüft.
