# together V1.2 technical changes

## 11. Tests
- Version-numbered tests moved out of the root into `test/regression/`.
- Domain/core and feature tests are grouped by responsibility.
- Release history now belongs in release documentation, not test filenames.

## 12. Domain/controller layer
- Added a lightweight `AsyncController<T>` base class.
- Added `TodayController` to isolate loading, error and cache behavior from `TodayPage`.
- Added `FoodPolicy` for structured food classification rules.

## 13. Offline/reconnect
- Added `NetworkStatusService` and an offline banner.
- Added non-sensitive JSON cache for foods and today's plan.
- Repository reads cache on network failure and refreshes it after successful requests.
- Cache is never an authorization source.

## 14. Dependency strategy
- Direct dependencies are pinned to exact versions.
- Added `DEPENDENCY_POLICY.md` with update and verification rules.
- Added `connectivity_plus 7.3.1` and `shared_preferences 2.5.5` for network state and local cache.

## 15. Food taxonomy
- `Food` now has structured `searchTerms`, `aliases`, `dietaryType`, `allergens`, and `proteinType`.
- Added Supabase migration `202609170003_v120_food_taxonomy.sql`.
- Recipe generation now consumes structured taxonomy fields instead of relying only on display-name heuristics.
- Food IDs are validated as the application's text IDs rather than UUIDs.
