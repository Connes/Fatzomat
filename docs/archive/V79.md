# V79 – Gespeichertes Rezept direkt in die gemeinsame Einkaufsliste

## Ziel

Ein gespeichertes Rezept kann aus „Meine Rezepte“ direkt als heutiger gemeinsamer Essensplan angelegt werden. Dabei wird die gemeinsame Einkaufsliste serverseitig aus den Rezeptzutaten aufgebaut.

## Änderungen

- Neue Aktion „Zur Einkaufsliste hinzufügen“ im Rezept-Kontextmenü.
- Vor dem Hinzufügen kann die Personenzahl von 1 bis 12 gewählt werden.
- Das bestehende `share_recipe_for_today`-RPC bleibt die einzige serverseitige Quelle für das Anlegen des Tagesplans und der Einkaufsliste.
- Ist bereits ein Tagesplan vorhanden, wird keine zweite Liste erzeugt. Stattdessen zeigt die UI den bestehenden Plan und bietet das Öffnen von „Heute“ an.
- Ist noch keine gemeinsame Verbindung vorhanden, führt die Aktion zur Verbindungsseite.
- Nach erfolgreichem Hinzufügen werden Rezeptliste und Tagesstatus neu geladen.
- Bestehende Aktion „Für uns heute freigeben“ bleibt erhalten.
- Version auf `0.1.0+79` erhöht.

## Datenbank

Keine neue Migration und kein neues RPC erforderlich. V79 verwendet ausschließlich den bereits vorhandenen und serverseitig geschützten `share_recipe_for_today`-Flow.

## Hinweis zur Architektur

Die aktuelle App besitzt pro Gerät eine gemeinsame Verbindung, nicht mehrere auswählbare Haushalte/„persönliche Apps“. Deshalb gibt es in V79 keinen künstlichen Haushalts-Auswahldialog. Die vorhandene Verbindung ist das Ziel der gemeinsamen Einkaufsliste.
