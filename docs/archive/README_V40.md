# Food App MVP v40

v40 führt die gemeinsame Rezeptsammlung und den optionalen Zwei-Personen-Modus ein. Die App bleibt vollständig alleine nutzbar.

## Neu
- Gespeicherte Rezepte bilden die gemeinsame gute Rezeptsammlung, sobald zwei Geräte verbunden sind.
- Eigene Lieblingsrezepte können direkt hinzugefügt werden.
- Verbindung über kurzen Code.
- Rezept „Für uns heute“ freigeben.
- Gemeinsame Einkaufsliste pro Tagesrezept.
- Synchronisierte Einkaufs-Häkchen.
- In-App-Benachrichtigungen in Echtzeit.

## Hinweis zu Push
Die fachliche Benachrichtigungslogik ist vorbereitet und die App zeigt neue Benachrichtigungen live an, solange sie geöffnet ist. Echte Betriebssystem-Push-Mitteilungen bei vollständig geschlossener App benötigen noch die jeweilige Android/iOS-Push-Konfiguration (FCM/APNs). Dafür werden bewusst keine fremden Projekt-Schlüssel in das ZIP eingebaut.
