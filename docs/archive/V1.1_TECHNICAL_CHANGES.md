# together V1.1 technische Änderungen

## Umgesetzt

1. CI-Quality-Gate: `flutter analyze`, `flutter test`, Android-Debug-Build.
2. Typed Domain Models: `Food` und erweiterte `Recipe` Modelle; typed Repository APIs sind der bevorzugte Weg.
3. Typed Recipe Validation: KI-Ergebnisse werden an der Repository-Grenze in `Recipe` Modelle überführt und validiert.
4. Zentrale Fehlerhierarchie: `AppException` mit Auth-, Authorization-, Network-, Validation-, Backend- und Unexpected-Fehlern.
5. Bootstrap/Quality Gate getrennt: `setup.sh` bootstrapped nur; `scripts/verify_release.sh` prüft und baut.

## Kompatibilität

Die bisherigen Map-Repository-Methoden bleiben vorübergehend als deprecated Adapter erhalten, damit ältere Feature-/Test-Adapter nicht abrupt brechen. Neue Produktlogik soll die typed APIs verwenden.

## Befehle

```bash
./setup.sh
./scripts/verify_release.sh
```

CI führt dieselben zentralen Qualitätsprüfungen aus.
